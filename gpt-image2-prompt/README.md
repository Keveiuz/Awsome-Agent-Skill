# yinyo-image2-prompt v1.6.0

> GPT-Image-2 万能 Prompt 工程师 — 35个子模板 + 5-Phase引导流程 🎨

## 这是什么

一个专门为 GPT-Image-2 设计的 prompt 工程 skill。不是案例集合，而是**AI内化的执行引擎**——读取后自动引导用户、识别场景、生成高质量 prompt。

## 为什么需要它

GPT-Image-2（2026-04-21 发布）和旧版本有根本性差异：
- "8K, ultra detailed, masterpiece" **完全无效**，浪费语义空间
- 负面提示词不如**正面约束**稳定
- 镜头参数有**物理效果**，不再是装饰
- 需要**结构化分段**，而不是一段话糊成一团

### 5-Phase引导流程

不是"填空题"，而是"帮用户想清楚自己要什么"：

1. **Phase 0**：复杂度判断 + 盲评有效性速查
2. **Phase 1**：场景+主题确认（5-6问）
3. **Phase 2**：按场景深度引导（每场景3-8个参数，附带盲评结论）
4. **Phase 3**：技术设置（尺寸/质量/数量/A/B双方案）
5. **Phase 4**：输出prompt + 用户确认（不直接调API）
6. **Phase 5**：生成后反馈循环

### 5大铁律

1. **主题前置** — 核心主体放 prompt 开头
2. **结构化场景** — 场景→主体→风格→镜头→光线→构图→约束
3. **文字用引号** — `"..."` 包裹，成功率 70% → 95%+
4. **明确镜头参数** — 焦距、光圈、角度有物理效果
5. **编辑分离变与不变** — `Change: ...` / `Preserve: ...`

## 与 image2-typography-poster 的边界

| 判断条件 | 使用哪个 skill |
|----------|---------------|
| 画面核心是"某个字/词"的字体设计 | → image2-typography-poster |
| 画面核心是场景、人物、产品、概念 | → yinyo-image2-prompt |
| 不确定 | → 先问用户"这张图的核心是文字还是画面？" |
